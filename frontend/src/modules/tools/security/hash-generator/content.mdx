## How it works

Type or paste text and it's hashed instantly using MD5, SHA-1, SHA-256, or SHA-512 — all computed locally in your browser via the Web Crypto API (MD5 uses a pure-JS implementation since it isn't part of the WebCrypto standard).

## Common use cases

- Verifying a file or string's checksum against a published hash.
- Generating a quick fingerprint for cache keys or deduplication.
- Comparing two payloads for equality without diffing full content.
