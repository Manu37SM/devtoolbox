## How it works

Enter a message and a secret key, choose a hash algorithm (SHA-1, SHA-256, SHA-384, or SHA-512), and the HMAC is computed locally using the browser's Web Crypto API. Output can be viewed as hex or base64. Nothing is transmitted anywhere.

## Common use cases

- Verifying webhook payload signatures.
- Generating API request signatures for authenticated endpoints.
- Checking message integrity and authenticity between two parties sharing a secret.
