## How it works

Pick a length and which character sets to include; a password is generated instantly using your browser's cryptographically secure random number generator, with an entropy estimate shown alongside it. Nothing is transmitted or stored.

## Common use cases

- Generating a strong password for a new account.
- Producing a batch of random secrets for local dev/test config.
- Understanding roughly how strong a password of a given length/charset is.
