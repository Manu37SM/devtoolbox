## How it works

Type a password and it's scored instantly by a local heuristic that checks length, character-class diversity (lowercase/uppercase/digits/symbols), common-password and dictionary-word matches against a small built-in list, and sequential or repeated-character patterns. Nothing you type is ever transmitted anywhere — this tool, like every tool in DevToolbox, runs entirely in your browser with no network calls.

## Common use cases

- Checking a new password's strength before using it for an account.
- Understanding why a password is considered weak and how to improve it.
- Getting a rough estimate of entropy and offline crack time.
