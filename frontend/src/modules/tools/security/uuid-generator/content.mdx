## How it works

Choose a UUID version and count, and unique identifiers are generated locally using your browser's cryptographically secure random number generator. Paste an existing UUID into the inspector to see its version and variant.

## Common use cases

- Generating primary keys or idempotency tokens for a database or API.
- Bulk-generating test fixture IDs.
- Checking whether a UUID you were handed is a valid v4/v7 identifier.
