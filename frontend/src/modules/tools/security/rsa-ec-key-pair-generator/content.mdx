## How it works

Pick RSA (with a modulus length) or EC (with a named curve) and generate a fresh public/private key pair using your browser's native WebCrypto API — the same PEM formats (`SPKI` for the public key, `PKCS8` for the private key) that `openssl` produces. Generation, signing capability, and export all happen locally; the private key is never sent anywhere.

## Common use cases

- Generating a throwaway key pair for local development, testing a signing flow, or a CI secret.
- Producing a quick EC key pair for JWT (ES256/ES384/ES512) or SSH experimentation.
- Understanding what a PEM-encoded public/private key actually contains without installing OpenSSL.
