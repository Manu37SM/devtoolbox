## How it works

Hash a password with bcrypt or Argon2id — both computed via WebAssembly implementations (`hash-wasm`) chosen for correctness parity with server-side libraries like Node's `bcrypt`/`argon2` packages — or switch to Verify mode to check a password against an existing hash string. Salts are generated locally with `crypto.getRandomValues`; the password and any hash you enter never leave your browser.

## Common use cases

- Generating a test bcrypt/Argon2id hash to seed a database or fixture without spinning up a backend.
- Verifying that a hash produced by your server matches an expected password during debugging.
- Comparing bcrypt cost factors or Argon2 memory/iteration parameters before choosing production settings.
