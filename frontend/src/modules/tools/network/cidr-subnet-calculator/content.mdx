## How it works

Enter an IPv4 address with a prefix length (e.g. `192.168.1.0/24`) and the network address, broadcast address, subnet mask, wildcard mask, usable host range, and host counts are computed locally using 32-bit binary arithmetic.

## Common use cases

- Planning IP address ranges when designing a network or VPC.
- Checking how many usable hosts a given subnet size provides.
- Verifying whether an address falls within a given CIDR block.
