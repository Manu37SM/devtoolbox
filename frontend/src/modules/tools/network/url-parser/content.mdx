## How it works

Paste any URL and it's broken down into its structural parts — protocol, credentials, host, port, path, query parameters, and hash — using the browser's native URL parser, so edge cases like IPv6 literals and internationalized domains are handled correctly. Nothing is sent anywhere; the breakdown happens entirely in your browser.

## Common use cases

- Inspecting a long tracking or redirect URL before clicking it.
- Pulling apart query parameters from a shared link.
- Checking exactly what host/port an API base URL resolves to.
- Debugging a malformed URL by seeing which part fails to parse.
