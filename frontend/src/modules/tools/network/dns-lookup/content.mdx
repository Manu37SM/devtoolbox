## How it works

You enter a domain and pick a record type, and the lookup is performed from our server. DNS resolution isn't available to browser JavaScript at all — there's no client-side API for querying DNS records — so this tool always requires a server round-trip.

## Common use cases

- Verifying an MX record is set up correctly before sending mail.
- Checking that a CNAME or A record has propagated after a DNS change.
- Debugging why a domain isn't resolving as expected.
