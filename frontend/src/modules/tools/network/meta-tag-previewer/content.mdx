## How it works

You enter a URL and our server fetches its HTML and extracts the Open Graph and standard meta tags (title, description, image, site name, favicon). Fetching an arbitrary third-party URL's HTML is blocked by CORS for almost every site — browsers won't let a page read the response of a fetch to a different origin unless that origin explicitly opts in — so this has to happen server-side.

## Common use cases

- Checking how a blog post or page will look when shared on Twitter, Slack, or Facebook before publishing.
- Debugging missing or incorrect Open Graph tags on your own site.
- Inspecting a third-party link's metadata without visiting it.
