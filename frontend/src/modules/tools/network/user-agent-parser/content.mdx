## How it works

Paste any User-Agent string (or start from your own browser's, prefilled automatically) and it's parsed locally into browser, operating system, device, rendering engine, and CPU details using the `ua-parser-js` library.

## Common use cases

- Debugging device- or browser-specific bugs reported by users.
- Understanding what a bot, crawler, or unfamiliar client string identifies as.
- Checking how a custom or spoofed User-Agent header will be interpreted.
