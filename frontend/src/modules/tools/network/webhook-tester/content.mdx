## How it works

Clicking "Create inbox" asks our server to allocate a temporary, publicly reachable URL. Receiving a real inbound HTTP request needs an endpoint the outside world can actually reach — a browser tab can't listen for incoming connections — so this tool is inherently server-based. Your browser then polls our server every few seconds to fetch the requests that URL has captured; nothing about the captured traffic is stored beyond the inbox's short expiry window.

## Common use cases

- Inspecting the exact payload a third-party service (Stripe, GitHub, etc.) sends to a webhook.
- Debugging a webhook integration before you have a real endpoint to point it at.
- Verifying headers and signatures on inbound requests during development.
