## How it works

Enter an IP address, or leave the field blank to look up your own, and the lookup runs on our server. Your browser has no built-in way to determine its own public IP address or geolocate any IP — that information only exists from the perspective of a server the request passes through — so this always requires a server round-trip.

## Common use cases

- Checking your own public IP address before configuring a firewall rule or allowlist.
- Investigating the rough geographic origin or hosting provider of a suspicious IP.
- Verifying an API request or webhook came from the expected IP range.
