## How it works

Choose numbers or strings, set a range/length and count, and get cryptographically random values generated locally using your browser's secure random number generator.

## Common use cases

- Generating test fixture IDs or sample data.
- Picking a random number for a raffle or dice-roll simulation.
- Generating random tokens or codes of a specific length/charset.
