## How it works

Pick a record type — person, address, company, product, or internet user — set a count, and get an array of realistic fake JSON records generated locally with `@faker-js/faker`. Provide a seed to get reproducible output across runs.

## Common use cases

- Seeding a database or API mock with realistic-looking sample data.
- Populating UI prototypes and demos without using real personal data.
- Generating reproducible fixtures for automated tests via a fixed seed.
