## How it works

Define a field schema — a name and a type (UUID, name, email, phone, boolean, number, date, and more) per field — and set a record count to generate sample JSON, optionally wrapped in a `{ "data": [...] }` envelope like a typical REST API response. Backed by the same Faker.js library the Fake/Mock Data Generator uses, entirely client-side.

## Common use cases

- Mocking a REST API response shape before the real backend endpoint exists.
- Generating realistic-looking sample data for a frontend demo or test fixture.
- Quickly producing a JSON array with a specific field shape for a `json-server`-style mock.
