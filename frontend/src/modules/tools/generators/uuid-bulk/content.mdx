## How it works

Set a count (up to 10,000) and an export format, and a batch of UUIDs is generated instantly using the same engine as the UUID Generator tool, ready to copy or download.

## Common use cases

- Seeding a database or test fixture with a large batch of unique IDs.
- Generating a CSV of IDs for a bulk import job.
- Producing a JSON array of IDs for a mock API response.
