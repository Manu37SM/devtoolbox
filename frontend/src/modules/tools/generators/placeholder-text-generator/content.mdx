## How it works

Pick a theme — Hipster, Corporate buzzword, or Bacon/meat ipsum — plus a unit (words, sentences, or paragraphs) and a count, and themed placeholder text is generated instantly from a curated word bank. Hit "Regenerate" for a fresh random draw with the same settings.

## Common use cases

- Filling mockups and prototypes with placeholder text that's more fun to read than classic lorem ipsum.
- Testing how a layout handles longer/shorter text without needing real copy yet.
- Generating throwaway sample content for demos and screenshots.
