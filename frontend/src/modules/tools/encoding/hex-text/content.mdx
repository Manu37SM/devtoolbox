## How it works

Type or paste text, hex, or binary and pick the matching conversion mode. Hex output can use space-separated byte pairs or a continuous string, and all conversions use UTF-8 byte encoding so multi-byte Unicode characters round-trip correctly. Everything happens locally in your browser.

## Common use cases

- Inspecting the raw byte representation of a string while debugging encodings.
- Converting hex dumps from network captures or memory tools back to readable text.
- Building test fixtures that need binary or hex representations of strings.
- Teaching or demonstrating how UTF-8 encodes characters as bytes.
