## How it works

Paste a JWT and its header, payload, and expiry are decoded instantly and entirely in your browser — the token itself is never sent anywhere. Signature verification is a separate, explicit opt-in step where you supply the key yourself.

## Common use cases

- Inspecting claims in an access token while debugging an auth flow.
- Checking whether a token has expired.
- Verifying the algorithm and type declared in the header.
