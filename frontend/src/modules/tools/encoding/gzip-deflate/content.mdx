## How it works

Compress text using Gzip, Deflate, or raw Deflate directly in your browser via the native CompressionStream API, with the result shown as base64 so it's easy to copy and paste. Switch to decompress mode and paste base64-encoded compressed data back in to recover the original text. A size line shows how much smaller (or larger) the compressed output is.

## Common use cases

- Estimating how well a payload will compress before sending it over the wire.
- Decompressing a base64 gzip blob copied from logs or an API response.
- Producing compressed test fixtures for compression-aware code paths.
- Comparing Gzip vs Deflate output size for the same input.
