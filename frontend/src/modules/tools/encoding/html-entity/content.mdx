## How it works

Paste HTML or plain text. Encode mode escapes `& < > " '` (and optionally all non-ASCII characters) to entities; decode mode resolves named and numeric entity references back to their characters.

## Common use cases

- Safely embedding user-generated text inside HTML markup.
- Decoding entity-encoded text copied from a CMS or email export.
- Sanitizing text before inserting it into a template.
