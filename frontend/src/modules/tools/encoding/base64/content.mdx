## How it works

Paste text or Base64 into the input pane; the output updates as you type. Encoding and decoding happen locally — nothing is uploaded.

## Common use cases

- Encoding binary-safe strings for embedding in JSON, URLs, or headers.
- Decoding Base64-encoded API tokens or config values while debugging.
- Producing URL-safe Base64 for use in query parameters or file names.
