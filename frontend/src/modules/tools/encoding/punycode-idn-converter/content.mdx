## How it works

Enter an internationalized domain name (with accented or non-Latin characters) to get its ASCII-only Punycode form with the standard "xn--" prefix on each affected label, or switch direction to decode a Punycode domain back to readable Unicode. Each dot-separated label is converted independently, matching how DNS and browsers actually handle IDNs.

## Common use cases

- Registering or debugging a domain name that contains non-ASCII characters.
- Decoding a suspicious "xn--" domain from a link or email to see what it actually spells out (a common phishing/homograph trick).
- Understanding what a browser's address bar is really sending over DNS for an internationalized URL.
