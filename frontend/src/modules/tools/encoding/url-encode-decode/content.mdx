## How it works

Paste a URL or query string and choose encode or decode. Component mode (`encodeURIComponent`) escapes every reserved character, useful for query parameter values; full-URI mode (`encodeURI`) leaves URL-structural characters like `/`, `?`, and `&` untouched.

## Common use cases

- Building a safe query string value from user-entered text.
- Decoding a percent-encoded URL to inspect what it actually points to.
- Debugging a malformed redirect or webhook URL.
