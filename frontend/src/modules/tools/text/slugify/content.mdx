## How it works

Type or paste text and each line is converted into a URL-safe slug: normalized, lowercased (optional), stripped of accents (optional), with non-alphanumeric characters collapsed into a single separator and trimmed from the ends. Multi-line input is slugified line by line, making it easy to batch-convert a list of titles.

## Common use cases

- Generating URL slugs for blog post or page titles.
- Converting a list of product names into slug-friendly identifiers.
- Creating clean anchor IDs or filenames from arbitrary text.
