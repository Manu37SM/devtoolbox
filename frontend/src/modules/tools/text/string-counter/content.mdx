## How it works

Paste or type any text and see live counts for characters, words, lines, sentences, and paragraphs, plus a UTF-8 byte size and estimated reading time — all computed locally as you type.

## Common use cases

- Checking a tweet or meta description fits a character limit.
- Estimating reading time for a blog post draft.
- Getting a quick word count for an assignment or article.
