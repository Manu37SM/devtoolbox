## How it works

Paste text in any common casing convention — it's tokenized into words and re-joined in whichever target case you pick, updating live as you type.

## Common use cases

- Converting a database column name (`snake_case`) to a JS variable name (`camelCase`).
- Renaming a CSS class to `kebab-case`.
- Generating a `CONSTANT_CASE` environment variable name.
