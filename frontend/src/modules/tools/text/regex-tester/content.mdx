## How it works

Type a regular expression and test string, and every match — including numbered and named capture groups — is highlighted live using JavaScript's native regex engine, entirely in your browser.

## Common use cases

- Debugging a regex before dropping it into application code.
- Extracting structured data (emails, IDs) from a block of text.
- Previewing a find-and-replace pattern before running it.
