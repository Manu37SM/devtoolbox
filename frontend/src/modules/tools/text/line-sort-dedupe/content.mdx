## How it works

Paste multi-line text and choose a sort order (alphabetical, reverse alphabetical, numeric, by length, or random shuffle) plus a dedupe mode (exact or case-insensitive). Optionally trim whitespace from each line and remove empty lines. Everything runs locally and updates instantly.

## Common use cases

- Cleaning up lists of URLs, emails, or IDs before importing them elsewhere.
- Alphabetizing a list of names or keywords.
- Removing duplicate log lines or entries from a dataset.
