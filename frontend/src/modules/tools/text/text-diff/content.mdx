## How it works

Paste two versions of text and see the differences highlighted, at your choice of line, word, or character granularity, computed locally.

## Common use cases

- Comparing two versions of a config file or document.
- Spotting exactly what changed between two API response payloads.
- Reviewing edits to a paragraph of text.
