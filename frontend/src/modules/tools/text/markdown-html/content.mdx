## How it works

Type Markdown and see it converted to HTML with a live, sanitized preview — entirely in your browser. The generated HTML is passed through DOMPurify before being rendered, so pasted content can't inject scripts into the preview.

## Common use cases

- Previewing a README or GitHub-flavored Markdown snippet before publishing.
- Converting Markdown notes into HTML for an email or CMS.
- Checking how Markdown formatting will render before committing it.
