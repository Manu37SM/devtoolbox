## How it works

Paste tabular data as CSV, TSV, or a Markdown table, choose an output format, and it's converted instantly. CSV/TSV parsing handles quoted cells and embedded delimiters; Markdown parsing skips the header separator row; the ASCII output draws a box-drawing table sized to the widest cell in each column.

## Common use cases

- Converting a CSV export into a Markdown table for documentation or a README.
- Turning a Markdown table back into CSV for a spreadsheet.
- Producing a clean ASCII table for terminal output or plain-text reports.
