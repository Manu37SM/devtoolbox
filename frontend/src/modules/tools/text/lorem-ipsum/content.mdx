## How it works

Choose a unit (words, sentences, paragraphs, or list items) and a count, and placeholder text is generated instantly, starting with the classic "Lorem ipsum dolor sit amet" opener by default.

## Common use cases

- Filling a design mockup or wireframe with realistic-length placeholder copy.
- Generating dummy content for a CMS or component while building layout.
- Stress-testing text wrapping/truncation with variable-length paragraphs.
