## How it works

Paste SVG markup and it's optimized instantly and entirely in your browser using SVGO — nothing is uploaded. Choose an optimization level, optionally strip the `viewBox`, and toggle multipass optimization for a smaller result.

## Common use cases

- Shrinking SVG icons and illustrations exported from design tools before shipping them to production.
- Stripping editor cruft (comments, metadata, unused IDs) from hand-authored or AI-generated SVGs.
- Comparing before/after file size to see exactly how much an SVG asset can be trimmed.
