## How it works

Set a width, height, background/text color, and optional label — a self-contained SVG placeholder image is generated instantly, previewed live, and ready to copy as markup or use as a data URI. Nothing leaves your browser, and there's no server-generated image to fetch.

## Common use cases

- Filling wireframes or mockups with correctly-sized dummy images before real assets exist.
- Quick "coming soon" or broken-image-style placeholders for prototypes.
- Generating a lightweight inline SVG placeholder instead of pulling from a third-party placeholder image service.
