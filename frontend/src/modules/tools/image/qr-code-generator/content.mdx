## How it works

Type text, a URL, or fill in the WiFi/vCard forms, and a QR code is generated instantly and entirely in your browser — nothing is uploaded.

## Common use cases

- Generating a QR code linking to a URL for print or a slide.
- Sharing WiFi credentials as a scannable code instead of typing a password.
- Creating a vCard QR code for a business card or email signature.
