## How it works

Upload an image and pick a color vision deficiency type — protanopia, deuteranopia, tritanopia, or full achromatopsia — to see an approximation of how it would look. Processing happens entirely in your browser via `<canvas>` pixel manipulation; nothing is uploaded anywhere.

This uses simplified sRGB approximation matrices (the same widely-used coefficients found in most browser-based simulators), not a full physiologically precise linear-light cone-response model — a documented v1 simplification, good enough for a quick accessibility sanity check but not a clinical-grade simulation.

## Common use cases

- Spot-checking whether a chart, map, or UI still reads clearly for common color vision deficiencies before shipping it.
- Reviewing a color palette or data visualization for a colorblind-friendly design pass.
- Demonstrating to a team why relying on color alone (e.g. red/green status dots) is risky.
