## How it works

Upload a source image (ideally square) and it's resized to every standard favicon and PWA icon size — 16×16, 32×32, 48×48, 180×180 (apple-touch-icon), 192×192, and 512×512 — entirely in your browser. Download individual sizes or the whole bundle as a zip.

## Common use cases

- Generating a complete favicon set for a new website from a single logo.
- Producing the `icon-192.png`/`icon-512.png` PWA manifest icons a web app manifest references.
- Creating an apple-touch-icon without needing design tool access.
