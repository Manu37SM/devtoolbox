## How it works

Paste a `.env` file's contents to format it: sort keys, strip comments or blank lines, and normalize quoting. Duplicate keys and malformed lines are flagged as warnings without blocking the rest of the file from formatting.

## Common use cases

- Cleaning up a `.env` file before committing an `.env.example`.
- Catching duplicate or malformed environment variable definitions.
- Enforcing a consistent quoting style across a team's env files.
