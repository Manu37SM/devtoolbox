## How it works

Paste HTML and it's formatted instantly using Prettier, including any embedded `<style>`/`<script>` blocks — entirely in your browser.

## Common use cases

- Cleaning up minified HTML pulled from a live page while debugging.
- Formatting a template snippet before sharing it.
- Enforcing consistent indentation on hand-written markup.
