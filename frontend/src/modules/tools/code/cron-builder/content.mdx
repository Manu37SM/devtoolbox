## How it works

Type a standard 5-field cron expression (minute, hour, day-of-month, month, day-of-week) and see a plain-language description plus the next several run times, computed locally in UTC (the timezone most schedulers evaluate cron expressions in by default).

## Common use cases

- Validating a cron expression before adding it to a CI pipeline or scheduler.
- Understanding what an unfamiliar cron expression from a config file actually does.
- Checking when a job will next run.
