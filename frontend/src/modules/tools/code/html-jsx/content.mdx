## How it works

Paste HTML markup and get back valid JSX: `class` becomes `className`, `for` becomes `htmlFor`, kebab-case attributes become camelCase, inline `style` strings become style objects, and void elements are self-closed — all computed locally.

## Common use cases

- Converting a static HTML mockup into a React component.
- Pasting markup copied from a design tool or another site into JSX.
- Cleaning up HTML snippets before dropping them into a `.tsx` file.
