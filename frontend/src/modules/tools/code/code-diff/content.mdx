## How it works

Paste the "before" and "after" versions of a source file and see a unified, line-by-line diff computed locally — with syntax highlighting for the language you pick.

## Common use cases

- Reviewing what changed between two revisions of a file before committing.
- Comparing a snippet you're about to paste against the original.
- Spotting accidental formatting or logic changes in generated code.
