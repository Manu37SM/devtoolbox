## How it works

Paste raw CSS declarations to get suggested Tailwind utility classes, or paste Tailwind classes to expand them back to CSS. Exact matches against Tailwind's default spacing, font-size, border-radius, and font-weight scales map to named utilities (e.g. `16px` → `m-4`); values outside those scales fall back to Tailwind's arbitrary-value syntax (e.g. `17px` → `m-[17px]`) so nothing is silently dropped. A curated set of common hex colors maps to named color utilities; other colors also use the arbitrary-value form.

This covers a deliberately bounded set of common properties — spacing (margin/padding/width/height/gap), colors, typography (font-size/font-weight/text-align/font-style/text-transform), layout (display/position/overflow/flex/align/justify), and border-radius — not Tailwind's full utility surface. Declarations or classes outside that set are listed separately rather than guessed at.

## Common use cases

- Converting a copy-pasted CSS snippet into Tailwind classes while migrating a component.
- Reading unfamiliar Tailwind classes in someone else's markup by expanding them back to plain CSS.
- Sanity-checking whether a spacing/color value lands on Tailwind's default scale or needs an arbitrary value.
