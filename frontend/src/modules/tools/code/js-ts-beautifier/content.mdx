## How it works

Paste JavaScript or TypeScript and it's formatted instantly using Prettier, running entirely in your browser — nothing is sent to a server.

## Common use cases

- Cleaning up minified or inconsistently-formatted JS pasted from elsewhere.
- Formatting a code snippet before sharing it.
- Enforcing consistent quote/semicolon style on a one-off file.
