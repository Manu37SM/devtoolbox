## How it works

Paste or type JSON into the input pane and it's formatted instantly — entirely in your browser, nothing is sent to a server. Invalid JSON is flagged inline with the exact line and column of the problem, so you don't have to hunt through a wall of minified text to find a missing comma.

## Common use cases

- Pretty-printing a minified API response while debugging.
- Validating a config file before committing it.
- Minifying JSON before shipping it over the wire.
- Normalizing key order to get a clean diff between two payloads.
