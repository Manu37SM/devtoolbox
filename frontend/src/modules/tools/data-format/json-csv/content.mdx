## How it works

Paste a JSON array of objects and it's converted to CSV, with nested objects flattened using dot notation by default. CSV input is parsed back to a JSON array, handling quoted fields and embedded commas/newlines correctly (RFC 4180-style).

## Common use cases

- Exporting an API response as a CSV for a spreadsheet.
- Converting a CSV export back into JSON for a script or import job.
- Flattening nested JSON records into a tabular format.
