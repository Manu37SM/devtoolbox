## How it works

Paste JSON or TOML and switch direction with the toggle above the editor. The conversion runs entirely in your browser using a lightweight TOML parser, so nothing leaves your machine. Nested objects become TOML tables and arrays of objects become arrays of tables automatically.

## Common use cases

- Migrating a config file from JSON to TOML (or vice versa) for tools like Cargo, Poetry, or Hugo.
- Inspecting a `pyproject.toml` or `Cargo.toml` as structured JSON for scripting.
- Converting API responses into a human-friendly TOML config format.
- Validating that a hand-written TOML file parses correctly before committing it.
