## How it works

Paste XML and it's parsed and re-serialized with consistent indentation. Malformed XML (unclosed tags, mismatched elements) is flagged with an error message.

## Common use cases

- Pretty-printing a minified XML API response or config file.
- Validating hand-written XML before committing it.
- Cleaning up inconsistently-indented XML from different tools.
