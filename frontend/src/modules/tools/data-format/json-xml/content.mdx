## How it works

Paste JSON or XML and pick a direction. Attributes map to `@_`-prefixed keys, text content maps to `#text` when siblings exist, and repeated sibling tags become arrays — a convention shared with popular JS XML libraries so the mapping is predictable.

## Common use cases

- Converting a SOAP/XML API response into JSON for easier scripting.
- Generating an XML payload (e.g., an RSS feed fragment) from a JSON object.
- Inspecting attributes and nested structure of an XML document as JSON.
