## How it works

Paste CSV or TSV data into the input pane and switch between converting CSV to TSV, TSV to CSV, or cleaning messy delimited data. Clean mode trims whitespace from every cell, drops fully-empty rows, and removes duplicate header rows that show up more than once. Everything runs locally in your browser.

## Common use cases

- Converting a spreadsheet export from CSV to TSV for pasting into another tool.
- Turning tab-separated clipboard data into proper CSV for a script.
- Cleaning up a CSV file that was pasted together from multiple exports with repeated headers.
- Stripping stray whitespace and blank rows before importing data into a database.
