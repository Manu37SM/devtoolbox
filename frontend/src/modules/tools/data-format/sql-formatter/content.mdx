## How it works

Paste a SQL query into the input pane and it's reformatted instantly using consistent indentation, line breaks, and keyword casing. Choose a dialect to correctly handle syntax specific to PostgreSQL, MySQL, SQLite, MariaDB, or BigQuery, and everything runs locally in your browser.

## Common use cases

- Cleaning up minified or copy-pasted SQL before reviewing it in a PR.
- Normalizing keyword casing across a team's saved queries.
- Making a long query with nested joins and subqueries readable.
- Standardizing indentation before committing a migration file.
