## How it works

Paste YAML — such as a Kubernetes manifest or CI config — and it's re-formatted with consistent indentation. Syntax errors are reported inline with line/column position.

## Common use cases

- Cleaning up inconsistently-indented YAML before committing it.
- Validating a CI/CD or Kubernetes config file's syntax before deploying.
- Normalizing YAML formatting across a team.
