## How it works

Paste a sample JSON document and get a draft-07 JSON Schema inferred from its shape — types, nested objects, and array item schemas are detected automatically. Toggle whether every observed field should be marked `required`, useful when your sample doesn't include every optional field.

## Common use cases

- Bootstrapping a JSON Schema for API request/response validation.
- Documenting the shape of a config file or webhook payload.
- Generating a starting point for `ajv` or other schema validators.
- Quickly checking what types a JSON payload actually contains.
