## How it works

Paste a JSON document, type a JMESPath expression, and see the matched result update instantly as you type. Everything runs in your browser using the JMESPath reference implementation, so both the document and the query stay local.

## Common use cases

- Prototyping a JMESPath query before embedding it in an AWS CLI `--query` flag.
- Extracting a subset of fields from a large API response for debugging.
- Filtering array items by condition (e.g. `items[?active].id`) without writing a script.
- Verifying an expression works before wiring it into application code.
