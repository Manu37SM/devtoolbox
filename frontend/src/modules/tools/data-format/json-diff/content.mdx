## How it works

Paste two JSON documents into the "Before" and "After" panes and get a structural diff — not a line-by-line text diff — that walks both documents field by field. Added, removed, and changed values are listed by their full path (e.g. `user.age`), so reordered keys or different formatting never produce false positives.

## Common use cases

- Comparing two versions of an API response to spot a regression.
- Reviewing a config change before deploying it.
- Checking that a refactor didn't accidentally change output shape.
- Diffing two snapshots of test fixture data.
