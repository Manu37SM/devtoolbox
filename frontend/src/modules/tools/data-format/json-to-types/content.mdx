## How it works

Paste a sample JSON document, pick a target language, and get type definitions generated instantly — TypeScript interfaces, Go structs with JSON tags, or Python dataclasses with typing imports. Nested objects and arrays are recursively converted into their own named types.

## Common use cases

- Generating TypeScript interfaces for an API response you don't control.
- Scaffolding Go structs to unmarshal a JSON payload.
- Creating Python dataclasses to model a config or fixture file.
- Quickly documenting the shape of a JSON contract for another team.
