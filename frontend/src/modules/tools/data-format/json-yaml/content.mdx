## How it works

Paste JSON or YAML and pick a direction; the conversion runs instantly and locally using a standard YAML parser.

## Common use cases

- Converting a Kubernetes/CI YAML config to JSON for programmatic editing.
- Turning a JSON API response into readable YAML for a config file.
- Sanity-checking that hand-written YAML parses the way you expect.
