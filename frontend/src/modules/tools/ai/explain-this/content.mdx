## How it works

Paste a regex, cron expression, JSON Schema, or SQL query and this tool sends it to Claude (Anthropic's AI model) with a task-specific prompt asking for a short, plain-language explanation. The request goes through DevToolbox's AI Gateway, which applies rate limits and never stores what you send beyond an anonymized token-count record for billing purposes.

## Common use cases

- Understanding a regex you inherited from someone else's code.
- Double-checking what a cron expression actually schedules before deploying it.
- Getting a quick summary of what a SQL query does without tracing through every join.
- Explaining a JSON Schema's constraints in plain English for a teammate.
