## How it works

Describe the pattern you want to match, optionally with example strings, and Claude (Anthropic's AI model) generates a regular expression. The result is only shown as "Confirmed" once it's been deterministically checked to compile and to actually match every example string you provided — a generation that doesn't match your examples is flagged "Not confirmed" rather than presented as correct.

## Common use cases

- Getting a starting-point regex for a validation pattern (email, phone number, custom ID format) without writing it from scratch.
- Turning a handful of real example values into a pattern that matches all of them.
- Prototyping quickly, then refining the result by hand in the Regex Tester/Debugger.
