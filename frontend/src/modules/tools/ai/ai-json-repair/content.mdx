## How it works

Most malformed JSON is broken in mechanical, predictable ways — a trailing comma, an unquoted key, single quotes instead of double, a stray comment. Those are fixed instantly on our server without ever involving AI. Only when that deterministic pass fails — usually because of genuinely ambiguous structural damage, like a truncated payload or mismatched brackets — does this tool fall back to asking Claude (Anthropic's AI model) to reconstruct the most plausible valid JSON. The result always tells you which path fixed it.

## Common use cases

- Cleaning up JSON copied from a log file, a Python dict literal, or a JS object with unquoted keys.
- Recovering from a truncated API response or config file.
- Fixing JSON with trailing commas left over from an edited array or object.
