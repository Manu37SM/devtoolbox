## How it works

Paste a code snippet (optionally naming its language) and Claude adds inline comments and docstrings/JSDoc explaining non-obvious logic. The code itself is left unchanged — only comments are added.

## Common use cases

- Documenting a function before committing it, without writing every comment by hand.
- Understanding unfamiliar code by having it annotated inline.
