## How it works

Paste a sample JSON API response, pick `fetch` or `axios`, and optionally name the response type. Claude generates a typed TypeScript client function that calls an endpoint returning that shape, plus the TypeScript type/interface for the response.

## Common use cases

- Scaffolding a typed client function from a real API response instead of writing the type by hand.
- Quickly prototyping how to consume a new endpoint during integration work.
