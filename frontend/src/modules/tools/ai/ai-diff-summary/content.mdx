## How it works

Paste a "before" and "after" version of some text or JSON and Claude (Anthropic's AI model) summarizes what actually changed in plain language — meant to answer "what changed and why does it matter", not restate every line-level addition and deletion the way a raw diff does.

## Common use cases

- Summarizing a large config or API response diff for a PR description or changelog.
- Understanding what changed in a JSON document without reading a wall of `+`/`-` lines.
- Getting a quick "what's different" answer for two versions of a document.
