## How it works

Paste example data — a handful of strings you want a regex to match, or a single sample JSON document — and Claude infers the pattern or schema, with no natural-language description required. Regex results are only shown as "Confirmed" once they've been deterministically checked to compile and match every example string you supplied.

## Common use cases

- Turning real sample values (IDs, log lines, phone numbers) into a matching regex without describing the format by hand.
- Getting a starting-point JSON Schema from a single example response or config file.
- Quickly sketching a pattern to refine further in the Regex Tester/Debugger or JSON Schema Generator.
