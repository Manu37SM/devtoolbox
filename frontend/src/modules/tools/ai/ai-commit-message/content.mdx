## How it works

Paste a git diff and Claude generates a single-line, conventional-commits-style commit message plus a longer PR description, based only on what the diff shows.

## Common use cases

- Drafting a commit message quickly after `git diff --staged` instead of writing one from scratch.
- Getting a starting-point PR description for a review, especially for larger or multi-file diffs.
