## How it works

Type a number in any supported base and its binary, octal, decimal, and hexadecimal equivalents update instantly. Arbitrary-precision integers are supported via BigInt, not limited to 53-bit safe integers.

## Common use cases

- Converting a hex color or memory address to decimal.
- Checking a binary flag value's decimal/hex representation.
- Debugging octal file permission values.
