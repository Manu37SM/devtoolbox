## How it works

Enter a Unix timestamp (seconds or milliseconds) to see it as ISO 8601, UTC, your local time, and a relative ("2 hours ago") format — or enter a human-readable date to get its timestamp back.

## Common use cases

- Debugging a `created_at`/`exp` field from an API response or JWT.
- Converting a log timestamp to your local timezone.
- Getting the current Unix time for a script or test fixture.
