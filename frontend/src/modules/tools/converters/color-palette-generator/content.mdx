## How it works

Pick a base color and a scheme (monochromatic, complementary, analogous, triadic, tetradic, or shades) to generate a palette of hex colors by rotating hue or varying lightness, computed locally.

## Common use cases

- Generating a coordinated color scheme for a UI mockup.
- Finding complementary or analogous accent colors for a brand color.
- Producing a set of shades of a single color for a design system.
