## How it works

Enter a color as hex, `rgb()`, or `hsl()` and see it converted to every format instantly, with a live swatch preview.

## Common use cases

- Converting a design tool's HEX value to CSS `rgb()`/`hsl()`.
- Getting a CMYK approximation for print handoff.
- Quickly previewing what a color code looks like.
