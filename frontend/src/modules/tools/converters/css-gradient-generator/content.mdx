## How it works

Pick a gradient type, adjust the angle, and add or remove color stops — the CSS `background` value updates live along with a preview swatch. Nothing leaves your browser.

## Common use cases

- Prototyping a hero section or button background gradient before writing it into a stylesheet.
- Recreating a gradient seen elsewhere by matching its colors and stop positions.
- Generating conic gradients for pie-chart-style UI without doing the CSS math by hand.
