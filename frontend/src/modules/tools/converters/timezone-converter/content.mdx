## How it works

Pick a date and time, choose the timezone it's in, then add any number of target timezones to see that same instant converted, computed locally with the browser's `Intl` API.

## Common use cases

- Scheduling a meeting across multiple offices in different timezones.
- Converting a server log timestamp into your local time.
- Checking what time it is somewhere else right now.
